# CineX Frontend

React + Vite frontend for the CineX booking platform.

## Environment

Create a local env file from `.env.example`.

Required values:

- `VITE_API_BASE_URL`
- `VITE_CLERK_PUBLISHABLE_KEY`

## Scripts

- `npm run dev`
- `npm run build`
- `npm run preview`

## Phase 1 goal

The frontend now reads the backend URL from environment configuration instead of a hardcoded local API origin.
